# datasciencecoursera
Created a GitHub repository named datasciencecoursera to organize coursework, R scripts, and project files while practicing Git version control and tracking changes.
# Data Sharing and Reproducible Research

## Introduction
Data sharing is an important part of data science. It helps researchers and analysts share information, collaborate, and make their work transparent and reproducible.

## Key Learnings

### 1. RStudio
- Created and managed RStudio projects.
- Practiced working with R scripts and project files.
- Understood the importance of organizing data analysis work.

### 2. Git Version Control
- Learned how to track changes in project files.
- Understood commits and version history.
- Practiced managing project updates using Git.

### 3. GitHub
- Created a GitHub repository.
- Uploaded and published Markdown files.
- Learned how to fork existing repositories.
- Explored how GitHub supports collaboration and data sharing.

### 4. Importance of Data Sharing
- Improves collaboration between data science teams.
- Supports transparency and reproducibility.
- Makes project resources easier to access and maintain.
- Encourages knowledge sharing and reuse.

## Conclusion
Working with RStudio, Git, and GitHub has helped me understand the basics of version control, project management, and collaborative data sharing. These skills provide a good foundation for future data science projects.
